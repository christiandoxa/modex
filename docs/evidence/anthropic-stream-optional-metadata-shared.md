# Anthropic stream metadata and delta handling across Prodex releases

The frozen Prodex 0.165.1 source at `10ae15b5d1806302b60f051e4e6fec788044f4c2` and 0.439.2 source at `72b77478a5198fc5da6b4d2253137f9cdbf43be9` have byte-identical Anthropic stream readers (`crates/prodex-app/src/runtime_launch/proxy_startup/anthropic_messages_sse_reader.rs`, SHA-256 `5b74e79588e7e5793abd9edf6c48bdb968745b7563b9423276ac9676ce3de6a3`) and action policies (`crates/prodex-mojo-core/src/anthropic_stream_policy.rs`, SHA-256 `bc08e05490f8b37ed8496c16d5f610aba5be2cfd49bb1e4c87ef57777044abb3`). Their compiled policy implementation at `mojo/prodex_core/anthropic_stream_policy.mojo` is also identical (SHA-256 `cb215804970ce80d90977b73623412a23ca934c45dedbfc29536684566a5bd18`).

The shared reader also tolerates missing or wrongly typed optional `message_start` metadata and usage, ignores unusable `message_delta.usage` counters, and ignores non-string text-delta payloads. `observe_value` passes optional message ID/model and usage to `observe_usage`, and passes raw optional `delta.text` onward; `observe_usage` updates counters only for values convertible with `Value::as_u64()` (reader lines 122–129, 156–161, and 381–395). The release's own stream-policy fixture has a `message_start` containing only an ID and a `message_delta` without usage (443–454).

The compiled policy defaults to `Ignore`, selects actions for `text_delta`, `input_json_delta`, and `thinking_delta`, and leaves other string delta types ignored. In an ordinary content block, a missing or non-string `delta.type` selects `MissingDeltaType` (ignored result blocks and active searches have separate precedence). The source tests explicitly expect `signature_delta` and an unknown string to be ignored. The reader converts `Ignore` to no output and emits `response.failed` for `MissingDeltaType`. Unknown deltas are ignored before their block index or extra event fields affect processing, so both releases ignore `citation_delta` even with a missing or nonnumeric index and extra root fields.

Modex now ignores an unknown string delta type before validating fields it will not consume. It still validates the delta object and string type, and preserves the existing text and input-JSON paths. Missing, null, or numeric delta types continue to fail. The recognized `thinking_delta` action emits Responses reasoning events for string `thinking` fields, including when no matching thinking block start was seen. Modex keeps no per-index thinking-block state. It separately tracks open web-search result indexes so thinking deltas on search and result blocks remain ignored.

`tests/test_anthropic_stream_optional_metadata_shared.py` compares the real `modex super` launch path with both frozen Linux oracle binaries. It covers 24 optional-metadata variants, a repeated-search input-JSON stream with extra event-root fields, six unknown string type variants (`citation_delta`, `signature_delta`, and `future_delta`, each with and without an extra root field), two `future_delta` controls with a missing or nonnumeric index, and six missing/null/numeric type variants with and without an extra root field. The unknown-type streams produce the same normalized response events in Modex and both releases. All malformed-type cases produce `response.failed` in all three processes, though their failure diagnostics are not identical: the releases use `invalid_anthropic_stream` and append `response.created`, while Modex uses `provider_stream_error` and emits only the failure event.

The suite compares `thinking_delta` in an in-order block, before any block start, and amid 256 overlapping thinking-block starts followed by a delta and stops. Both release binaries emit the same reasoning events and complete each stream; Modex matches their normalized responses. A separate control holds 128 web-search result indexes open together, sends thinking deltas against them, and closes them in reverse order; Modex matches both releases and suppresses those deltas. This exercises result-index lookup with overlapping blocks but does not set a runtime state limit. The suite also compares orphan stops with extra event fields and stops with missing or nonnumeric indexes against both releases. The 0.165.1 characterization suite covers duplicate, orphan, and mismatched tool-use stops. The frozen reader's `native_anthropic_stream_emits_live_reasoning_events` unit test covers the in-order form.

A separate production-path control covers a pending search followed by `message_delta`, a repeated result start after its stop, and decreasing search indexes (4 then 2). The pending-search case verifies `response.output_item.added` sequence 0, `response.created` sequence 1, `response.output_item.done` sequence 2, and `response.completed` sequence 3. Repeated result starts after stop are ignored. Decreasing search indexes are accepted and their thinking deltas remain suppressed; search-added events keep arrival order while deferred done events and final output follow ascending `output_index`. Modex uses a search-index dictionary for lookups and sorts a temporary index list for pending completion; both oracles match these events.

Each test run isolates HOME, state, work, and loopback ports, uses a fake Codex client and `synthetic-provider-key`, and makes no external provider requests. The suite checks the oracle SHA-256 values:

- Prodex 0.165.1: `dd5a4354e067cbbb44e00a2fd1f59843aeb267d17db116e37896d5e305279a51`
- Prodex 0.439.2: `a545b602bddfbbc2b4455d8dd7e97263e9c49747fa9d1d6b94011e73971d2a5e`

Reproduce with `make build` followed by `python3 scripts/ci/run-unittest.py test_anthropic_stream_optional_metadata_shared.py`. Fast and Full CI run this check in the existing cross-release lane after acquiring both pinned oracles.

Citation data is still not translated into Responses output; the releases also ignore these citation events. Modex has no aggregate cap on retained per-stream search and tool state, and the temporary pending-index sort list grows with pending searches; the 128-result control is finite test input, not a bound. This evidence does not establish parity for other malformed Anthropic fields, other providers, or the six release targets. The malformed delta-type tests establish fail-closed behavior, not exact diagnostic parity. The broader inventory remains incomplete.
